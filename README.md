Prompts and distilled rulebooks accompanying a conference submission on
reducing the instruction-phrasing sensitivity of a frozen VLA policy.

- prompts/: rephrase generation, rule distillation, rule application, and
  the single-rule scaffold baseline
- rules/: nine distilled rulebooks (three evidence types x three draws)
- swings_full.pdf: every significant single-edit swing set the searches
  found, charted with exact p-values (the paper curates one set per task
  and edit category)
- data/: per-phrase records behind the swing charts, one row per phrase
  (set id, task, edit category, phrase, success rate, set gap, test stat)
